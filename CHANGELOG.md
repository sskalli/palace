# Changelog

## [0.6.0](https://github.com/sskalli/palace/pull/46) - 2026-11-03

### Added

- Drag and drop folders and Markdown files to import them into the open folder or workspace root.

### Changed

- The note's copy button is displayed only on hover and when the cursor is there.

### Fixed

- Added a scrollbar to the folders section in the left sidebar.

## [0.5.0](https://github.com/sskalli/palace/pull/41) - 2026-10-29

### Added

- Link folders in the note editor path to their corresponding folders.
- Wrap selections with characters such as `(`, `{`, `[`, `~`, and `*` instead of replacing them.
- Download individual notes or folders, preserving the folder hierarchy.
- Add a copy shortcut to single- and triple-backtick blocks without moving the cursor when clicked.
- Add a button next to the new-folder button to collapse all folders.
- Include folders in search.

### Removed

- Hide the wide editor on mobile.

## [0.4.0](https://github.com/sskalli/palace/pull/33) - 2026-10-27

### Changed

- Improved performance for note creation, opening, saving, and editing.

## [0.3.3](https://github.com/sskalli/palace/pull/30) - 2026-10-22

### Changed

- Improved Markdown rendering in write mode.
- Updated Next.js to 16.4.2 for a hotfix.

## [0.3.2](https://github.com/sskalli/palace/pull/26) - 2026-10-19

### Removed

- Removed the `n` shortcut for creating a new note.

## [0.3.1](https://github.com/sskalli/palace/pull/24) - 2026-10-19

### Removed

- Disabled live rendering for lists.

## [0.3.0](https://github.com/sskalli/palace/pull/22) - 2026-10-19

### Added

- Added live Markdown rendering in the note editor using CodeMirror.

## [0.2.0](https://github.com/sskalli/palace/pull/19) - 2026-10-19

### Added

- Use the note or folder title as the browser tab title when viewing it.
- Added a wide editor.

### Fixed

- Fixed the sidebar not collapsing on mobile when creating a note.
